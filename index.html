01 — Problem Statement

The Fake Review Crisis in Indian E-Commerce

India's e-commerce market is projected to reach $300 billion by 2030. The CCPA found that over 30% of reviews on major Indian platforms show detectable manipulation — and existing tools are built only for English.

🌐

Multilingual Gap

India has 22 scheduled languages. Reviews in Hindi, Tamil, Telugu, Gujarati, Bengali, and Marathi are invisible to English-only detectors.

🤖

AI-Generated Content

Instruction-tuned LLMs like GPT-4 have lowered the cost of fake review production to near zero, flooding platforms overnight.

🖼️

Manipulated Images

Traditional systems cannot detect AI-generated or semantically mismatched product images used to make fake reviews look authentic.

📉

Loss of Trust

Without reliable verification, consumers make poor purchase decisions and platform credibility deteriorates irreversibly.

02 — Innovation

What Makes This System Different

A unified pipeline combining text, image, and metadata signals — something no existing tool does.

🔤

No Translation Required

mBERT's shared multilingual vocabulary handles 6 regional languages natively, without translation overhead or accuracy loss.

🔍

AI-Text Fingerprinting

RoBERTa detects AI-generated text via perplexity patterns, syntactic uniformity, and token-repetition signals.

🖼️

Vision-Language Alignment

CLIP verifies whether a review photo is semantically consistent with the product description using a shared 512-dim embedding space.

📊

Unified Authenticity Score

XGBoost fuses all module outputs with reviewer metadata into a single calibrated score in range [0, 100].

🧩

Fully Modular Architecture

Each stage can be retrained or replaced independently. A review without an image still gets evaluated by Stages 1 and 2.

🚀

Zero Platform Cooperation

Deployable as a Chrome Extension and Flask API — works without any access or agreement from e-commerce operators.

03 — System Architecture

Four-Stage Sequential Pipeline

Every review is processed through four modular stages. Each stage outputs a scalar signal and a dense embedding consumed by the XGBoost fusion layer.

End-to-End Processing Flow
Input — Review Tuple
Text  ·  Language  ·  Image  ·  Reviewer Metadata
1

Multilingual Sentiment Analysis

mBERT · Fine-tuned

12-layer Transformer encoder pre-trained on 104 languages. Classifies sentiment (Positive / Neutral / Negative) across 6 Indian regional languages without translation. Outputs a 768-dim [CLS] embedding and a confidence score.

2

AI-Generated Text Detection

RoBERTa · Binary Classifier

Fine-tuned RoBERTa detects machine-generated review text by analyzing perplexity patterns, syntactic uniformity, and token-repetition signals. Binary output: Real or AI-Generated.

3

Photo-Review Image Verification

OpenAI CLIP · ViT-B/32

Encodes the review image and product description independently into a shared 512-dim embedding space. Cosine similarity threshold τ = 0.25 flags inauthentic images. Categories: Authentic / AI-Generated.

4

Feature Fusion & Authenticity Scoring

XGBoost · Gradient Boosted

Fuses all module outputs with reviewer metadata (account age, review history, rating pattern) into a single calibrated Authenticity Score A(r) ∈ [0, 100]. Implementation in progress.

Output — Authenticity Score
Real  |  Fake  |  AI-Generated  |  Low-Trust

06 — Deployment Plan

Consumer-Facing Deployment

Designed to work without cooperation from e-commerce platforms.

🧩

Chrome Extension

Manifest V3 JavaScript extension that intercepts product review pages and overlays an Authenticity Score badge in real time.

🌐

Flask Web App

Python REST API serving all four model modules. Supports JSON input with text, image URL, and metadata fields.

⚡

Modular Inference

Reviews without images skip Stage 3 automatically. The XGBoost fusion layer treats image absence as a weak negative signal.

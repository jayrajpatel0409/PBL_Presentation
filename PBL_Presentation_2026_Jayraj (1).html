Multilingual Sentiment Analysis And Fake Review Detection

"To develop an integrated AI-based system that accurately analyzes sentiment, detects AI-generated or deceptive reviews, validates attached images, and combines all outputs into a single, interpretable Authenticity Score to assess the trustworthiness of each review."

Problem Statement

E-commerce platforms suffer from fake, AI-generated, and misleading product reviews with manipulated images. Traditional systems cannot detect AI-generated content or verify image authenticity, resulting in unreliable ratings and loss of customer trust.

Literature Review

Reviewed recent papers on fake review detection using transformer models (BERT, RoBERTa), multimodal verification systems (CLIP), and multilingual sentiment analysis for e-commerce platforms.

Innovation

Integrated system combining sentiment analysis (mBERT), AI-generated text detection (RoBERTa), image verification (CLIP), and unified authenticity scoring (XGBoost) with support for multiple languages.

System Methodology

Dataset

EQUAL.csv dataset from Kaggle containing English product reviews with labels for sentiment classification and fake review detection. Custom multilingual dataset created for extended language support.

Model Architecture

mBERT for sentiment analysis, RoBERTa for AI-generated text detection, CLIP for image verification, and XGBoost for final authenticity scoring.
